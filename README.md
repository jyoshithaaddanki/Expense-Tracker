# 💰 Expense Tracker

A simple and responsive **Expense Tracker Web Application** built using HTML, CSS, and JavaScript. It helps users manage their income and expenses and keeps track of their current balance.

## 🚀 Features

* Add income and expenses
* Enter transaction description
* Select transaction category
* Calculate total income
* Calculate total expenses
* Display current balance
* Delete transactions
* Store data using LocalStorage
* Responsive design for mobile and desktop

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* LocalStorage

## 📁 Project Structure

```text
Expense-Tracker/
│
├── index.html
├── style.css
└── script.js
```

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Right-click and select **Open with Live Server**.
5. Start adding your income and expenses.

## 💡 How It Works

Users enter a transaction description, amount, type, and category. JavaScript automatically calculates the income, expenses, and balance. Transactions are stored in the browser using LocalStorage, so the data remains available after refreshing the page.
